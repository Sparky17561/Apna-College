    return new Promise((resolve,reject) =>{
        let internetSpeed = Math.floor(Math.random()*10)+1;
        if(internetSpeed < 4){

REST 

Representational State Transfer 

REST is a architectural style that defines a set of constraints to be used for creating web services 

CRUD operations

GET retrieves resources 
POST submits new data to the server 
PUT updates existing data 
PATCH updates existing data partially 
DELETE removes data 

Creating RESTful APIs 

GET  /posts          to get data for all posts   INDEX(Main cheez)

POST /posts          to add new post             CREATE

GET  /posts/:id      to get one post (using id)  VIEW

PATCH /posts/:id     to update specific post     UPDATE

DELETE /posts/:id    to delete specific post     DESTROY
